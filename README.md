# Fit21 破圈充能站 (Fit21 Shake Hero)

專為健康俱樂部教練與夥伴打造的街頭破圈行動輔助工具。

## ✨ 特色功能
- **🎯 今日 3 人試飲任務**：即時紀錄達成名單，內建 Web Audio 音效與 Canvas 慶祝彩帶
- **🛡️ 拒絕免疫鎧甲**：遊戲化收集「不用謝謝」，將拒絕轉化為經驗值
- **💡 27 條頂級大師心態卡**：收錄安東尼·羅賓、納瓦爾·拉維肯特及 10 位世界名家拒絕脫敏智慧（支援語音朗讀）
- **💬 黃金開場白**：「你好！我們在做健康飲品推廣，幫我們新口味做個試飲好嗎？」
- **⚡ 60 秒出門起跑儀式**：5 秒啟動法則，破除門口猶豫障礙
- **📱 PWA 支援**：可直接加到 iPhone / Android 主畫面，全螢幕獨立運行

## 🚀 如何開啟 GitHub Pages 免費網頁
1. 到 GitHub 倉庫設定 `Settings` ➔ `Pages`
2. Source 選擇 `Deploy from a branch`
3. Branch 選擇 `main` / `root` ➔ 按下 `Save`
4. 幾分鐘後即可獲得你的專屬 HTTPS 網址，在手機瀏覽器開啟並加到主畫面！
